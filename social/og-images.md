# Open Graph Images

## Purpose

This document defines the official Open Graph (OG) images used across Pharos websites.

OG images are used when pages are shared on platforms such as LinkedIn, X, Facebook, Discord, Slack and messaging applications.

Every important page should have a dedicated Open Graph image that accurately represents its content.

---

# Design Principles

Open Graph images should:

- represent the page clearly
- use official brand assets
- maintain visual consistency
- avoid excessive text
- remain readable on mobile devices
- use high-quality imagery only

---

# General Style

Preferred characteristics:

- Clean composition
- Strong typography
- Brand colors
- High contrast
- Minimal distractions
- Premium visual quality

Images should feel modern, professional and engineering-focused.

---

# Recommended Size

Preferred:

1200 × 630 px

Maintain a 1.91:1 aspect ratio whenever possible.

---

# Homepage

Image should communicate:

- Engineering excellence
- Premium software
- Innovation
- Modern technology

Avoid screenshots of products.

Instead, use a branded visual composition that represents Pharos as a technology company.

---

# Capability Pages

Each capability should have its own OG image.

Examples:

- Mobile Engineering
- AI Engineering
- Business Automation
- Cloud Backend Engineering
- Digital Experience Engineering

The image should visually reinforce the capability rather than display generic stock imagery.

---

# Case Studies

Every case study should use its own dedicated Open Graph image.

Preferred content:

- authentic screenshots
- product identity
- subtle branding
- project-specific visuals

Never reuse the homepage image.

---

# Products

Every product should have a dedicated image.

Examples:

- Petsupo
- Hubmonix
- LeadForge
- DevAudit
- DevClean

The visual should reflect the actual product whenever possible.

---

# Blog Articles

If a blog exists, article images should:

- support the topic
- use consistent branding
- remain visually clean
- avoid clickbait styling

---

# Technical Guidelines

Images should:

- be optimized for web delivery
- avoid excessive file size
- remain sharp on Retina displays
- preserve safe margins around important content

---

# Asset Selection

When selecting an OG image, Claude should prefer:

1. Official project artwork
2. Official screenshots
3. Official product renders
4. Branded abstract compositions

Never generate fictional product imagery when authentic assets exist.

---

# Consistency Rules

Open Graph images should feel like they belong to the same visual system.

Typography, spacing, colors and composition should remain consistent across all pages.
