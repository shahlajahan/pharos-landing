# Website Thumbnails

## Purpose

This document defines thumbnail usage across the Pharos website.

Thumbnails are small preview images used throughout the site for cards, grids, previews and navigation.

They should help users quickly recognize projects, products and content.

---

# Design Principles

Thumbnails should be:

- visually clean
- easy to recognize
- consistent
- authentic
- high quality

Small images should communicate identity immediately.

---

# Preferred Content

Use, in order of priority:

1. Real product screenshots
2. Official UI mockups
3. Product illustrations
4. Branded graphics

Avoid generic stock images.

---

# Project Cards

Each project should have a unique thumbnail.

Examples:

- Petsupo
- Hubmonix
- LeadForge
- DevAudit
- DevClean

Users should be able to recognize each project instantly.

---

# Capability Cards

Capability thumbnails should represent concepts rather than products.

Examples:

- Mobile Engineering
- AI Engineering
- Business Automation

Simple abstract visuals are preferred over literal illustrations.

---

# Blog Cards

Use topic-related imagery that follows the Pharos visual language.

Maintain consistent spacing and composition.

---

# Size Recommendations

Recommended ratio:

16:9

Alternative:

1:1

All thumbnails should remain sharp on high-density displays.

---

# Visual Style

Preferred characteristics:

- Minimal
- Premium
- Modern
- Engineering-focused
- High contrast
- Consistent lighting

Avoid decorative effects that reduce clarity.

---

# Cropping Rules

Important content should remain centered.

Avoid placing critical UI near edges.

Ensure thumbnails remain readable at very small sizes.

---

# File Optimization

Images should:

- load quickly
- remain visually sharp
- avoid unnecessary compression artifacts
- use modern image formats when appropriate

---

# Asset Selection

Claude should always prioritize authentic project assets.

If multiple assets are available, select the image that best communicates the project at small sizes.

Never invent product interfaces when official screenshots exist.

---

# Consistency

All thumbnails should appear as part of one unified design system.

Users should immediately recognize them as belonging to the Pharos brand.
